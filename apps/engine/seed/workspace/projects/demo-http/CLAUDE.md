# Create an HTTP service

Product: wso2-integrator

## Goal
The viewer creates an HTTP service in WSO2 Integrator with base path `/greeting` and a GET `hello`
resource that returns "Hello, World!".

## Audience
Developers new to WSO2 Integrator.

## Constraints
- Use the reference script `script.spec.ts` (hand-written, step 1.5). It is the template for agent-written scripts.
- Don't run the service yet; "Try It" isn't covered by the skill.
